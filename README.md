# Pollinator Meadow

A peaceful 3D platformer (Mario-64 style) set in a diverse meadow. Run, jump, double-jump and glide as a raccoon, robin, opossum or bear — or flutter as a honeybee, butterfly, hummingbird, moth or bat — and collect each animal's favourite food (worms and grubs, bugs, honeycomb, berries, nuts, sticks). Food is plentiful and respawns, nothing hunts or hurts anything, and every animal builds up its own home in four stages. Built with Three.js; play it in a phone browser.

Controls: left thumb to move, Jump button (tap twice for a double jump, hold to glide/flutter), Action button for the animal's special move; keyboard: WASD/arrows, Space, E.
