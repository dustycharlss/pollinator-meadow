# Pollinator Meadow

A peaceful 3D game where you fly on the backs of pollinators (honeybee, butterfly, hummingbird, moth, bat) through a diverse meadow, gather from their preferred flowers, and grow their nests. Built with Three.js; play it in a phone browser.

Credits: tap the ℹ button in the game, or see `credits.json` in this repo (CC-BY attributions and CC0 sources).
